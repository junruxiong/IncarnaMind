供在客户工作中使用 IncarnaMind 的事务所参考：如何向客户说明他们的文件会怎样处理，下面几段可以直接粘贴到委托函里。内容描述的是应用的实际行为，请对照你安装的版本核对，完整细节见 [privacy.md](privacy.md)。

## 给事务所（不放进函件）

把“可放入委托函的文字”下面几段粘贴到函件里，并填好方括号。
- **发出之前**，先打开应用的**设置 → 隐私**：这里列出了所有已开启的服务。
- **不要代替 AI 服务承诺“不用于训练”，**只保留适用的那一行。有些服务默认会用 API 数据训练模型，除非你选择退出，请阅读你所用服务的条款。如果你用的是“使用我的 ChatGPT 订阅”，请查看 OpenAI 关于通过 ChatGPT 订阅使用的条款。
- **另外：**
  - 删除的内容会在你的电脑上保留 30 天。
  - 被引用文档的旧版本会保留，方便引用继续打开。
  - 会议录音和保存的网页存放在你电脑上的应用数据文件夹里。
  - 如果开启了可选的搜索服务（例如 Cohere 或 Voyage），它会收到搜索结果片段。如果开启了云端搜索（托管的向量嵌入），文件全文会发送给该服务。
  - 应用的数据文件夹中保存着每个文件的可搜索文字副本。
  - 删除 30 天后，只留下一条很小的记录，表明它曾经存在。
  - 使用数据和崩溃报告默认关闭，需要你同意；受邀的测试版可能默认发送使用数据。
  - 开启“所有内容都留在这台电脑上”时，你添加的连接器仍可能被调用。

## 可放入委托函的文字

**我们如何使用 IncarnaMind。** 我们使用开源桌面应用 IncarnaMind，对照你们的文件核对我们的书面工作。它运行在我们自己的电脑上。

**你们的文件存放在哪里。** 你们的文件保存在我们的电脑上，就在我们存放它们的文件夹里。IncarnaMind 没有账号，也没有存放你们文件的服务器。按照设计，开发者从不接收你们的文件，也从不接收我们就这些文件提出的问题。

**发送什么，发给谁。** 回答问题或核对我们的工作时，IncarnaMind 只把任务需要的部分发送给我们选定的 AI 模型服务：[服务名称，例如 Anthropic]。这包括我们正在提问或核对的文字、你们文件中相关的段落及其名称和页码，以及它可以搜索的其他文件的名称。为整理你们的文件，它还可能发送文件的名称、目录和简短摘录；没有文字的扫描页，最多发送三张页面图片。如果我们开启云端搜索，你们文件的全文会发送给该服务。在我们于应用中选定某项服务之前，不会向它发送任何内容。

**训练和保留。** IncarnaMind 从不用你们的文件训练模型。模型服务会保留什么、是否用收到的内容训练模型，取决于我们的使用方式。[保留适用的那一行。]
- [使用我们自己的 API 密钥时：][该服务]的 API 条款适用：[该服务的数据条款，或“见[该服务]的 API 条款”]。
- [使用 ChatGPT 订阅时：]适用 OpenAI 关于通过 ChatGPT 订阅使用的条款。
- [开启“所有内容都留在这台电脑上”并使用在我们自己电脑上运行的模型时：]你们的文件和我们的问题不会发送给任何 AI 模型服务。

**你们的选择。** 如果你们不希望文件发送给任何模型服务，请告诉我们。我们会用在自己电脑上运行的模型，或不借助 AI，来核对我们的工作。
